# Pocket Notebook
Mobile PWA beat sampler (4 or 8 beat loops = 16/32 sixteenth steps), synth + piano roll. Static files, no backend.
Loop lengths: edit LENGTHS in app.js.
Companion app for waveform editing / multitrack: https://kmhkasper-boop.github.io/pocket-wave/
lame.min.js from lamejs 1.2.1 (LGPL).
